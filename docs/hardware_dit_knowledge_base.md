# DIT 存储现场边界

本项目只记录与 DIT Renamer 直接相关的现场约束。硬盘盒选购、系统引导、渗透测试、PE/Kali 和其他通用运维内容不属于本项目功能，已从项目文档移除。

## 卷级操作

- Apple Disk Image Media（包括 DMG、sparse image 等磁盘镜像挂载卷）不是摄影机卡，应用固定排除，不进入侧边栏或卷级操作流程。
- 任何卷级改名都应先暂停仍在读取或校验该卷的任务。
- 通过 BSD 分区节点定位目标，并用 Volume UUID 复核设备身份；BSD 节点本身可能在拔卡后被系统复用。
- 同名卷不能仅靠 `/Volumes/<名称>` 区分。不要按新名称猜测路径，也不要对不确定目标执行卸载。
- 文件系统的卷名长度、允许字符和大小写规则必须以实际文件系统及 macOS `diskutil` 返回结果为准；工具不应静默截断用户请求。

## 媒体识别

- `C####`、`A001_` 等文件名模式不是跨厂商身份证明。
- Sony、DJI、Nikon、RED、ARRI、Canon 等识别必须同时考虑官方目录结构、扩展名和机型设置。
- 证据不足、扫描被截断、空卡和照片卡只允许人工处理，不应自动生成 `A001` 等默认建议。

## 现场验证

执行后应确认：卷名已经在同一 BSD 分区上生效，Volume UUID 未改变，审计记录写入成功；若任一项无法确认，停止后续自动流程并人工检查。
