# DIT 存储卡现场要点

本文只记录 DIT Renamer 直接涉及的卷识别、卷名和现场操作边界。

## 卷级操作

- Apple Disk Image Media，包括 DMG 和 sparse image 挂载卷，不是摄影机卡，始终排除。
- 网络卷、系统虚拟卷和内置卷不进入卷级操作流程。
- 卷名修改前先暂停仍在读取、拷贝或校验该卷的任务。
- 目标通过 BSD 分区节点定位，并用 Volume UUID 复核。BSD 节点可能在拔卡后被 macOS 重新分配，不能单独作为设备身份。
- 同名卷不能仅靠 `/Volumes/<name>` 区分。卷名变化后也不要用新名称猜测挂载路径。
- 卷名的字符和长度限制以实际文件系统及 `diskutil` 返回结果为准。工具不会静默截断或改写用户输入。

## 媒体识别

- `C####`、`A001_` 等文件名模式只能作为观察线索，不能单独证明厂商或机型。
- Sony、DJI、Nikon、RED、ARRI 和 Canon 的判断应结合目录结构、扩展名、XML/XMP 和可用的机型信息。
- 扫描不完整、卡为空、只有照片、存在残留素材或无法确认机型时，只提供人工处理路径，不自动生成 `A001` 等默认卷名。

## 执行后检查

应确认新卷名已作用于原来的 BSD 分区，Volume UUID 未变化，重挂载后的挂载路径正确，审计记录也已保存。任一项无法确认时，停止后续自动流程并人工检查。
